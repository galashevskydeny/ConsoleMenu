# Требования к реализации ActionBar

ActionBar - модуль с панелью заклинаний и способностей персонажа.

## Кнопка

Кнопка – это фрейм для отображения способностей, находящихся в слотах, привязанных к этой кнопке.

**BUTTON-01:** У кнопки должен быть дочерний фрейм для отображения способности кнопки.

**BUTTON-01-01:** У фрейма для отображения способности кнопки должен быть дочерний фрейм для отображения иконки способности.
**BUTTON-01-01-01:** У фрейма для отображения иконки способности должны быть дочерние фреймы для двух иконок способностей (исходная и целевая). Эти дочерние фреймы будут использованы для создания эффекта «переворачивания монеты» для смены иконки отображаемой способности кнопки.
**BUTTON-01-01-02:** У фрейма для отображения иконки способности должна быть функция для включения десатурации отображаемой иконки.
**BUTTON-01-01-03:** У фрейма для отображения иконки способности должна быть функция для выключения десатурации отображаемой иконки.
**BUTTON-01-01-04:** У фрейма для отображения иконки способности должна быть таблица для хранения данных слотов, привязанных к сочетанию модификатора (CTRL/ALT/SHIFT) и кнопки.
**BUTTON-01-01-05:** У фрейма для отображения иконки способности должны быть функции для работы (пополнение, удаление, обновление) с таблицей хранения данных слотов.
**BUTTON-01-01-06:** У фрейма для отображения иконки способности должна быть функция для переключения отображаемой иконки.
**BUTTON-01-01-06-01:** Функция для переключения отображаемой иконки должна запускать анимацию «переворачивания монеты» для смены отображаемой иконки способности.
**BUTTON-01-01-07:** У фрейма для отображения иконки способности должна быть функция для увеличения размера.
**BUTTON-01-01-08:** У фрейма для отображения иконки способности должна быть функция для возврата штатного размера.

**BUTTON-01-02:** У кнопки должен быть дочерний фрейм для отображения кулдауна перезарядки отображаемой способности.
**BUTTON-01-02-01:** У фрейма перезарядки должна быть функция для показа перезарядки видимой способности.
**BUTTON-01-02-02:** У фрейма перезарядки должна быть функция для скрытия перезарядки.
**BUTTON-01-02-03:** У фрейма перезарядки должна быть функция для обновления перезарядки видимой способности.

**BUTTON-01-03:** У кнопки должен быть дочерний фрейм для отображения счетчика зарядов отображаемой способности.
**BUTTON-01-03-01:** У фрейма для отображения счетчика зарядов должна быть функция для показа числа зарядов видимой способности.
**BUTTON-01-03-02:** У фрейма для отображения счетчика зарядов должна быть функция для скрытия числа зарядов.
**BUTTON-01-03-03:** У фрейма для отображения счетчика зарядов должна быть функция для обновления числа зарядов видимой способности.

**BUTTON-02:** У кнопки должен быть дочерний фрейм для отображения свечения при активации способности.
**BUTTON-02-01:** В фрейме свечения должен быть дочерний фрейм для отображения анимированного вращающегося свечения.
**BUTTON-02-01-01:** У фрейма вращающегося свечения должна быть функция для воспроизведения повторяющейся анимации по текстуре.
**BUTTON-02-01-02:** У фрейма вращающегося свечения должна быть функция для остановки повторяющейся анимации.
**BUTTON-02-02:** В фрейме свечения должен быть дочерний фрейм для отображения анимированного взрыва искр.
**BUTTON-02-02-01:** У фрейма взрыва искр должна быть функция для воспроизведения разовой анимации по текстуре.
**BUTTON-02-02-02:** У фрейма взрыва искр должна быть функция для остановки разовой анимации.

**BUTTON-02-03:** У фрейма свечения должна быть функция для показа свечения.
**BUTTON-02-03-01:** В рамках функции показа свечения необходимо вызвать функцию воспроизведения повторяющейся анимации вращающегося свечения.
**BUTTON-02-03-02:** В рамках функции показа свечения необходимо вызвать функцию воспроизведения разовой анимации взрыва искр.
**BUTTON-02-04:** У фрейма свечения должна быть функция для скрытия свечения.
**BUTTON-02-04-01:** В рамках функции скрытия свечения необходимо вызвать функцию остановки повторяющейся анимации вращающегося свечения.
**BUTTON-02-04-02:** В рамках функции скрытия свечения необходимо вызвать функцию остановки разовой анимации взрыва искр.

**BUTTON-03:** У кнопки должен быть дочерний фрейм для отображения тени под кнопкой.
**BUTTON-03-01:** У фрейма тени должна быть функция для показа тени.
**BUTTON-03-02:** У фрейма тени должна быть функция для скрытия тени.

**BUTTON-04:** У кнопки должен быть дочерний фрейм для отображения пиктограммы с обозначением кнопки.
**BUTTON-04-01:** У фрейма пиктограммы должна быть функция для показа пиктограммы.
**BUTTON-04-02:** У фрейма пиктограммы должна быть функция для скрытия пиктограммы.
**BUTTON-04-03:** У фрейма пиктограммы должна быть функция для обновления пиктограммы.

**BUTTON-05:** У кнопки должна быть функция для обновления кнопки.
**BUTTON-05-01:** В рамках функции обновления кнопки необходимо обновить информацию об отображаемой способности.
**BUTTON-05-01-01:** После обновления информации об отображаемой способности необхоидмо запустить анимацию «переворачивания монеты», если происходит смена отображаемой способности из слота с привязкой к кнопке без модификаций на способность из слота с привязкой к кнокпке с модификатором.
**BUTTON-05-01-02:** Если происходит обновление кнопки и смена отображаемой способности не происходит (обновление в рамках обновления кнопки для отображения панели модификатора), то воспроизводить анимацию «переворачивания монеты» не надо.
**BUTTON-05-02:** В рамках функции обновления кнопки необходимо обновить информацию для счетчика зарядов.
**BUTTON-05-03:** В рамках функции обновления кнопки необходимо обновить информацию по перезарядке отображаемой способности.
**BUTTON-05-03-01:** Если необходимо просто обновить значение перезарядки, необхоимо вызвать функицю обновления перезарядки видимой способности.
**BUTTON-05-03-02:** Если необходимо скрыть значение перезарядки, необходимо вызвать функцию скрытия перезарядки.
**BUTTON-05-03-03:** Если необходимо показать значение перезарядки, необходимо вызвать функцию показа перезарядки видимой способности.
**BUTTON-05-04:** В рамках функции обновления кнопки необходимо обновить информацию о необхоидмости свечения.
**BUTTON-05-04-01:** Если по результатам обновления небходимо погасить свечение, то необхоидмо вызвать фукнцию для скрытия свечения у фрейма свечения, функцию для скрытия тени под кнопкой, функцию для возврата фрейма иконки к штатному размеру.
**BUTTON-05-04-02:** Если по результатам обновления небходимо зажечь свечение, то необхоидмо вызвать фукнцию для показа свечения у фрейма свечения, функцию для показа тени, функцию увеличения иконки способности.
**BUTTON-05-05:** В рамках функции обновления кнопки необходимо управлять десатурацией иконки отображаемой способности.
**BUTTON-05-05-01:** Если способность нельзя применить, необходимо вызвать функцию включения десатурации.
**BUTTON-05-05-02:** Если цель находится вне досягаемости, необходимо вызвать функцию включения десатурации.
**BUTTON-05-05-03:** Если у способности идёт собственная перезарядка, необходимо вызвать функцию включения десатурации. Общее восстановление после применения умения десатурацию не включает.
**BUTTON-05-05-04:** Если способность недоступна на текущем уровне, необходимо вызвать функцию включения десатурации.
**BUTTON-05-05-05:** Если в слоте находится предмет, который нельзя применить, необходимо вызвать функцию включения десатурации. Пустой слот по этому правилу не обесцвечивается.
**BUTTON-05-05-06:** Если нажат модификатор, и в слоте, привязанному к кнопке с модификатором, нет способности или никакой слот не привязан к кнопке с модификатором – т.е. нет способности для такого сочетания (состояния кнопки), необходимо вызвать функцию включения десатурации.
**BUTTON-05-05-07:** Если кнопка переключается на способность модификатора, включать десатурацию из-за отсутствия способности для этого сочетания не надо.
**BUTTON-05-05-08:** Если ни одно из условий включения десатурации не выполняется, необходимо вызвать функцию выключения десатурации.

**BUTTON-06:** У кнопки должна быть функция для включения отображения кнопки.
**BUTTON-06-01:** Перед отображением кнопки необходимо вызвать функцию для ее обновления.
**BUTTON-06-02:** После обновления кнопки необходимо вызвать анимацию появления через увеличение кнопки до штатного размера.

**BUTTON-07:** У кнопки должна быть функция для выключения отображения кнопки.
**BUTTON-07-01:** В рамках функции необходимо вызвать анимацию исчезновения через уменьшения размера до 0.
