# Требования к реализации ActionBar

ActionBar - модуль с панелью заклинаний и способностей персонажа.

## Кнопка

Кнопка – это фрейм для отображения способностей, находящихся в слотах, привязанных к этой кнопке.

**BUTTON-01:** У кнопки должен быть дочерний фрейм для отображения способности кнопки.

**BUTTON-01-01:** У фрейма для отображения способности кнопки должен быть дочерний фрейм для отображения иконки способности.
**BUTTON-01-01-01:** У фрейма для отображения иконки способности должны быть дочерние фреймы для двух иконок способностей (исходная и целевая). Эти дочерние фреймы будут использованы для создания эффекта «переворачивания монеты» для смены иконки отображаемой способности кнопки.
**BUTTON-01-01-02:** У фрейма для отображения иконки способности должна быть функция для включения десатурации отображаемой иконки.
**BUTTON-01-01-03:** У фрейма для отображения иконки способности должна быть функция для выключения десатурации отображаемой иконки.
**BUTTON-01-01-04:** У фрейма для отображения иконки способности должна быть таблица для хранения данных слотов, привязанных к сочетанию модификатора (CTRL/ALT/SHIFT) и кнопки.
**BUTTON-01-01-05:** У фрейма для отображения иконки способности должны быть функции для работы (пополнение, удаление, обновление) с таблицей хранения данных слотов.
**BUTTON-01-01-06:** У фрейма для отображения иконки способности должна быть функция для переключения отображаемой иконки.
**BUTTON-01-01-06-01:** Функция для переключения отображаемой иконки должна запускать анимацию «переворачивания монеты» для смены отображаемой иконки способности.

**BUTTON-01-02:** У кнопки должен быть дочерний фрейм для отображения кулдауна перезарядки отображаемой способности.
**BUTTON-01-02-01:** У фрейма перезарядки должна быть функция для показа перезарядки видимой способности.
**BUTTON-01-02-02:** У фрейма перезарядки должна быть функция для скрытия перезарядки.
**BUTTON-01-02-03:** У фрейма перезарядки должна быть функция для обновления перезарядки видимой способности.

**BUTTON-01-03:** У кнопки должен быть дочерний фрейм для отображения счетчика зарядов отображаемой способности.
**BUTTON-01-03-01:** У фрейма для отображения счетчика зарядов должна быть функция для показа числа зарядов видимой способности.
**BUTTON-01-03-02:** У фрейма для отображения счетчика зарядов должна быть функция для скрытия числа зарядов.
**BUTTON-01-03-03:** У фрейма для отображения счетчика зарядов должна быть функция для обновления числа зарядов видимой способности.

**BUTTON-02:** У кнопки должен быть дочерний фрейм для отображения свечения при активации способности.
**BUTTON-02-01:** В фрейме свечения должен быть дочерний фрейм для отображения анимированного вращающегося свечения.
**BUTTON-02-01-01:** У фрейма вращающегося свечения должна быть функция для воспроизведения повторяющейся анимации по текстуре.
**BUTTON-02-01-02:** У фрейма вращающегося свечения должна быть функция для остановки повторяющейся анимации.
**BUTTON-02-02:** В фрейме свечения должен быть дочерний фрейм для отображения анимированного взрыва искр.
**BUTTON-02-02-01:** У фрейма взрыва искр должна быть функция для воспроизведения разовой анимации по текстуре.
**BUTTON-02-02-02:** У фрейма взрыва искр должна быть функция для остановки разовой анимации.

**BUTTON-02-03:** У фрейма свечения должна быть функция для показа свечения.
**BUTTON-02-04:** У фрейма свечения должна быть функция для скрытия свечения.

**BUTTON-03:** У кнопки должен быть дочерний фрейм для отображения тени под кнопкой.
**BUTTON-03-01:** У фрейма тени должна быть функция для показа тени.
**BUTTON-03-02:** У фрейма тени должна быть функция для скрытия тени.

**BUTTON-04:** У кнопки должен быть дочерний фрейм для отображения пиктограммы с обозначением кнопки.
**BUTTON-04-01:** У фрейма пиктограммы должна быть функция для показа пиктограммы.
**BUTTON-04-02:** У фрейма пиктограммы должна быть функция для скрытия пиктограммы.
**BUTTON-04-03:** У фрейма пиктограммы должна быть функция для обновления пиктограммы.

**BUTTON-05:** У кнопки должна быть функция для обновления кнопки.

**BUTTON-06:** У кнопки должна быть функция для включения отображения кнопки.

**BUTTON-06:** У кнопки должна быть функция для выключения отображения кнопки.
