# Требования к реализации ActionBar

ActionBar - модуль с панелью заклинаний и способностей персонажа.

## Кнопка

Кнопка – это фрейм для отображения способностей, находящихся в слотах, привязанных к этой кнопке.

**BUTTON-01:** У кнопки должен быть дочерний фрейм для отображения способности кнопки.

**BUTTON-01-01:** У фрейма для отображения способности кнопки должен быть дочерний фрейм для отображения иконки способности.
**BUTTON-01-01-01:** У фрейма для отображения иконки способности должны быть дочерние фреймы для двух иконок способностей (исходная и целевая). Эти дочерние фреймы будут использованы для создания эффекта «переворачивания монеты» для смены иконки отображаемой способности кнопки.
**BUTTON-01-01-02:** У фрейма для отображения иконки способности должна быть функция для включения десатурации отображаемой иконки.
**BUTTON-01-01-03:** У фрейма для отображения иконки способности должна быть функция для выключения десатурации отображаемой иконки.
**BUTTON-01-01-04:** У фрейма для отображения иконки способности должна быть таблица для хранения данных слотов, привязанных к сочетанию модификатора (CTRL/ALT/SHIFT) и кнопки.
**BUTTON-01-01-04-01:** В таблице кнопки хранится слот, привязанный к кнопке без модификатора.
**BUTTON-01-01-04-02:** В таблице кнопки хранятся слоты, привязанные к кнопке с модификаторами SHIFT, CTRL и ALT.
**BUTTON-01-01-05:** У фрейма для отображения иконки способности должны быть функции для работы (пополнение, удаление, обновление) с таблицей хранения данных слотов.
**BUTTON-01-01-06:** У фрейма для отображения иконки способности должна быть функция для переключения отображаемой иконки.
**BUTTON-01-01-06-01:** Функция для переключения отображаемой иконки должна запускать анимацию «переворачивания монеты» для смены отображаемой иконки способности.
**BUTTON-01-01-07:** У фрейма для отображения иконки способности должна быть функция для увеличения размера.
**BUTTON-01-01-07-01:** В рамках функции увеличения размера необходимо вызвать анимацию увеличения фрейма.
**BUTTON-01-01-08:** У фрейма для отображения иконки способности должна быть функция для возврата штатного размера.
**BUTTON-01-01-08-01:** В рамках функции возврата штатного размера необходимо вызвать анимацию уменьшения фрейма.

**BUTTON-02:** У кнопки должен быть дочерний фрейм для отображения кулдауна перезарядки отображаемой способности.
**BUTTON-02-01:** У фрейма перезарядки должна быть функция для показа перезарядки видимой способности.
**BUTTON-02-01-01:** Функция показа перезарядки должна вызывать frame:Show() для фрейма перезарядки.
**BUTTON-02-02:** У фрейма перезарядки должна быть функция для скрытия перезарядки.
**BUTTON-02-03:** У фрейма перезарядки должна быть функция для обновления перезарядки видимой способности.
**BUTTON-02-03-01:** Функция обновления перезарядки должна записать в показанный фрейм новое время восстановления способности.

**BUTTON-03:** У кнопки должен быть дочерний фрейм для отображения счетчика зарядов отображаемой способности.
**BUTTON-03-01:** У фрейма для отображения счетчика зарядов должна быть функция для показа числа зарядов видимой способности.
**BUTTON-03-01-01:** В рамках функции показа числа зарядов необходимо вызвать анимацию появления.
**BUTTON-03-02:** У фрейма для отображения счетчика зарядов должна быть функция для скрытия числа зарядов.
**BUTTON-03-02-01:** В рамках функции скрытия числа зарядов необходимо вызвать анимацию исчезновения.
**BUTTON-03-03:** У фрейма для отображения счетчика зарядов должна быть функция для обновления числа зарядов видимой способности.

**BUTTON-04:** У кнопки должен быть дочерний фрейм для отображения свечения при активации способности.
**BUTTON-04-01:** Во фрейме свечения должен быть дочерний фрейм для отображения анимированного вращающегося свечения.
**BUTTON-04-01-01:** У фрейма вращающегося свечения должна быть функция для воспроизведения повторяющейся анимации по текстуре.
**BUTTON-04-01-02:** У фрейма вращающегося свечения должна быть функция для остановки повторяющейся анимации.
**BUTTON-04-02:** Во фрейме свечения должен быть дочерний фрейм для отображения анимированного взрыва искр.
**BUTTON-04-02-01:** У фрейма взрыва искр должна быть функция для воспроизведения разовой анимации по текстуре.
**BUTTON-04-02-02:** У фрейма взрыва искр должна быть функция для остановки разовой анимации.

**BUTTON-04-03:** У фрейма свечения должна быть функция для показа свечения.
**BUTTON-04-03-01:** В рамках функции показа свечения необходимо вызвать функцию воспроизведения повторяющейся анимации вращающегося свечения.
**BUTTON-04-03-02:** В рамках функции показа свечения необходимо вызвать функцию воспроизведения разовой анимации взрыва искр.
**BUTTON-04-04:** У фрейма свечения должна быть функция для скрытия свечения.
**BUTTON-04-04-01:** В рамках функции скрытия свечения необходимо вызвать функцию остановки повторяющейся анимации вращающегося свечения.
**BUTTON-04-04-02:** В рамках функции скрытия свечения необходимо вызвать функцию остановки разовой анимации взрыва искр.
**BUTTON-04-04-03:** В рамках функции скрытия свечения необходимо скрывать фреймы анимаций свечения и взрыва.
**BUTTON-04-04-03-01:** При скрытии фреймов анимаций свечения и взрыва необходимо вызвать анимацию исчезновения.
**BUTTON-04-05:** У фрейма свечения должна быть функция для увеличения размера.
**BUTTON-04-05-01:** В рамках функции увеличения размера необходимо вызвать анимацию увеличения фрейма.
**BUTTON-04-06:** У фрейма свечения должна быть функция для возврата штатного размера.
**BUTTON-04-06-01:** В рамках функции возврата штатного размера необходимо вызвать анимацию уменьшения фрейма.

**BUTTON-05:** У кнопки должен быть дочерний фрейм для отображения тени под кнопкой.
**BUTTON-05-01:** У фрейма тени должна быть функция для показа тени.
**BUTTON-05-01-01:** В рамках функции показа тени необходимо вызвать анимацию появления.
**BUTTON-05-02:** У фрейма тени должна быть функция для скрытия тени.
**BUTTON-05-02-01:** В рамках функции скрытия тени необходимо вызвать анимацию исчезновения.

**BUTTON-06:** У кнопки должен быть дочерний фрейм для отображения пиктограммы с обозначением кнопки.
**BUTTON-06-01:** У фрейма пиктограммы должна быть функция для показа пиктограммы.
**BUTTON-06-01-01:** В рамках функции показа пиктограммы необходимо вызвать анимацию появления.
**BUTTON-06-02:** У фрейма пиктограммы должна быть функция для скрытия пиктограммы.
**BUTTON-06-02-01:** В рамках функции скрытия пиктограммы необходимо вызвать анимацию исчезновения.
**BUTTON-06-03:** У фрейма пиктограммы должна быть функция для обновления пиктограммы.

**BUTTON-07:** У кнопки должна быть функция для обновления кнопки.
**BUTTON-07-01:** В рамках функции обновления кнопки необходимо обновить информацию об отображаемой способности.
**BUTTON-07-01-01:** После обновления информации об отображаемой способности необходимо запустить анимацию «переворачивания монеты», если способность из слота, привязанного к кнопке без модификатора, сменяется на способность из слота, привязанного к кнопке с модификатором.
**BUTTON-07-01-02:** Если при обновлении кнопки отображаемая способность не меняется (кнопка обновляется для показа панели модификатора), анимацию «переворачивания монеты» воспроизводить не надо: нужно только сменить иконку отображаемой способности.
**BUTTON-07-01-03:** Отображаемая способность берётся из таблицы кнопки: из слота без модификатора или из слота с нажатым модификатором SHIFT, CTRL или ALT.
**BUTTON-07-02:** В рамках функции обновления кнопки необходимо обновить данные счетчика зарядов.
**BUTTON-07-02-01:** Если в таблице панели заклинаний для этой способности не надо показывать счетчик, необходимо вызвать функцию скрытия числа зарядов.
**BUTTON-07-02-02:** Если в таблице панели заклинаний для этой способности надо показывать счетчик, необходимо вызвать функцию показа числа зарядов.
**BUTTON-07-02-02-01:** При показе счетчика необходимо вызвать функцию обновления числа зарядов. На счетчик записывается значение, пришедшее от API.
**BUTTON-07-02-03:** В таблицу панели заклинаний для способности записывается true, если хотя бы раз от API пришло значение, отличное от пустой строки.
**BUTTON-07-02-03-01:** Запись true в таблицу защищает счетчик от скрытия, когда для него приходят секретные значения.
**BUTTON-07-02-03-02:** Таблица признака показа счетчика хранится у кнопки.
**BUTTON-07-03:** В рамках функции обновления кнопки необходимо обновить информацию о перезарядке отображаемой способности.
**BUTTON-07-03-01:** Если отображаемая способность на перезарядке, эта перезарядка не является общим восстановлением после применения умения, и фрейм перезарядки уже показан, необходимо вызвать функцию обновления перезарядки видимой способности.
**BUTTON-07-03-02:** Если отображаемая способность не на перезарядке или идёт только общее восстановление после применения умения, необходимо вызвать функцию скрытия перезарядки.
**BUTTON-07-03-02-01:** Функция скрытия перезарядки должна вызвать анимацию исчезновения.
**BUTTON-07-03-03:** Если перезарядка отображаемой способности началась, эта перезарядка не является общим восстановлением после применения умения, и фрейм перезарядки ещё скрыт, необходимо вызвать функцию показа перезарядки видимой способности.
**BUTTON-07-03-04:** Пока кнопка переключается, и отсчёт новой способности ещё не готов, необходимо вызвать функцию скрытия перезарядки.
**BUTTON-07-04:** В рамках функции обновления кнопки необходимо обновить информацию о необходимости свечения.
**BUTTON-07-04-01:** Если по результатам обновления необходимо погасить свечение, необходимо вызвать функцию для скрытия свечения, функцию для скрытия тени под кнопкой, функцию для возврата фрейма иконки к штатному размеру и функцию для возврата фрейма свечения к штатному размеру.
**BUTTON-07-04-02:** Если по результатам обновления необходимо зажечь свечение, необходимо вызвать функцию для показа свечения, функцию для показа тени, функцию для увеличения иконки способности и функцию для увеличения фрейма свечения.
**BUTTON-07-05:** В рамках функции обновления кнопки необходимо управлять десатурацией иконки отображаемой способности.
**BUTTON-07-05-01:** Если способность нельзя применить, необходимо вызвать функцию включения десатурации.
**BUTTON-07-05-02:** Если цель находится вне досягаемости, необходимо вызвать функцию включения десатурации.
**BUTTON-07-05-03:** Если способность на перезарядке и эта перезарядка не является общим восстановлением после применения умения, необходимо вызвать функцию включения десатурации.
**BUTTON-07-05-04:** Если способность недоступна на текущем уровне, необходимо вызвать функцию включения десатурации.
**BUTTON-07-05-05:** Если в слоте находится предмет, который нельзя применить, необходимо вызвать функцию включения десатурации. Пустой слот по этому правилу не обесцвечивается.
**BUTTON-07-05-06:** Если нажат модификатор, а способности для сочетания кнопки с этим модификатором нет (в привязанном слоте нет способности или слот не привязан), необходимо вызвать функцию включения десатурации.
**BUTTON-07-05-07:** Если кнопка переключается на способность модификатора, включать десатурацию из-за отсутствия способности для этого сочетания не надо.
**BUTTON-07-05-08:** Если ни одно из условий включения десатурации не выполняется, необходимо вызвать функцию выключения десатурации.

**BUTTON-08:** У кнопки должна быть функция для включения отображения кнопки.
**BUTTON-08-01:** Перед отображением кнопки необходимо вызвать функцию для её обновления.
**BUTTON-08-02:** После обновления кнопки необходимо вызвать анимацию увеличения размера кнопки до штатного размера, AnimatedScaleUp.

**BUTTON-09:** У кнопки должна быть функция для выключения отображения кнопки.
**BUTTON-09-01:** В рамках функции необходимо вызвать анимацию исчезновения через уменьшение размера до 0.
**BUTTON-09-01-01:** Для исчезновения кнопки необходимо вызвать анимацию уменьшения фрейма.
**BUTTON-09-02:** В рамках функции необходимо вызвать функцию скрытия свечения.
**BUTTON-09-03:** В рамках функции необходимо вызвать функцию скрытия тени.
**BUTTON-09-04:** В рамках функции необходимо вызвать функцию скрытия числа зарядов.
**BUTTON-09-05:** В рамках функции необходимо вызвать функцию скрытия перезарядки.

## Группа кнопок

Группа кнопок – это фрейм с несколькими кнопками, расположенных близко друг к другу на геймпаде.

**GROUP-BUTTON-01:** Кнопки - дочерние фреймы группы кнопок.

**GROUP-BUTTON-02:** У фрейма группы кнопок должен быть дочерний фрейм с тенью группы кнопок.
